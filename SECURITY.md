# Security Policy

## Supported Versions

Only the latest release. Each merge to `main` releases a new image, and the cluster runs it.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/zimmertr/Mountaineers-Activity-Scraper/security/advisories/new).
Do not open a public issue for security problems.

Include what you found, where it lives (file, workflow, or image), and how to reproduce it.

What to expect:

- **Acknowledgement** within a few days. This is a one-person project, so response times are best effort.
- **Fix**: a confirmed vulnerability is fixed in the next release.
- **Credit** in the advisory, unless you'd rather not.

## Scope

In scope: the scraper, its image and the CI workflows.

Out of scope: The Mountaineers' website and the Google APIs the scraper calls. Report issues in those to their owners.

There is no bounty program. Reports are still appreciated.
